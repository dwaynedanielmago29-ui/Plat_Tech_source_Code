BANKER'S ALGORITHM | SYSTEM SIMULATOR

Project Description

The Banker's Algorithm System Simulator is a Python-based application that demonstrates how the Banker's Algorithm works in Operating Systems. It determines whether the system is in a safe state by analyzing available resources, allocated resources, and the maximum resource requirements of each process.

The application uses a graphical user interface (GUI) to make resource allocation and safety checking easier to understand and simulate.

Features

- Graphical User Interface (GUI)
- Available Resources Input
- Allocation Matrix
- Maximum Demand Matrix
- Input Validation
- Resource Allocation Checking
- Safety Algorithm Simulation
- Safe Sequence Detection
- Safe and Unsafe State Results

Technologies Used

- Python
- Tkinter
- Unittest

How to Run

1. Make sure Python is installed on your computer.
2. Download or clone the repository.
3. Open the project folder.
4. Run the application using:

python main.py

How to Run Tests

To run the unit tests, use:

python -m unittest test_bankers.py

Purpose of the Project

This project aims to help students understand the Banker's Algorithm, resource allocation, deadlock avoidance, and safe sequences in Operating Systems through an interactive simulation.
